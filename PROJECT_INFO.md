# FinFlow - Детальная информация о проекте

## Обзор

FinFlow - это комплексное решение для автоматизации финансового учета малого бизнеса, объединяющее в себе:

1. **Telegram-бот** для удобного взаимодействия
2. **OCR-систему** для автоматического распознавания чеков
3. **Аналитическую платформу** для анализа расходов
4. **Систему рекомендаций** для оптимизации бюджета
5. **Интеграцию с 1С** для синхронизации данных

## Архитектура проекта

### Модульная структура

```
FinFlow/
├── bot/                    # Telegram Bot модуль
├── core/                   # Основная бизнес-логика
├── django_app/            # Django приложение с моделями
├── ocr/                   # OCR распознавание чеков
├── analytics/             # Аналитика и отчеты
├── integrations/          # Внешние интеграции
└── config/                # Конфигурация Django
```

### Принципы проектирования

- **Разделение ответственности** - каждый модуль отвечает за свою область
- **Сервис-ориентированная архитектура** - бизнес-логика вынесена в сервисы
- **Dependency Injection** - слабая связанность между компонентами
- **Асинхронность** - использование async/await для I/O операций

## Технические детали

### Backend (Django 5.0)

- **Python 3.13** - последняя версия Python
- **Django 5.0** - современный веб-фреймворк
- **Django REST Framework** - API для фронтенда
- **PostgreSQL** - надежная реляционная БД
- **Redis** - кэширование и очереди

### Telegram Bot (aiogram 3.22)

- **aiogram 3.22** - современная библиотека для Telegram Bot API
- **FSM (Finite State Machine)** - управление состояниями диалога
- **Inline кнопки** - удобный пользовательский интерфейс
- **Webhook поддержка** - для продакшн развертывания

### OCR система

- **Tesseract** - открытый OCR движок
- **OpenCV** - обработка изображений
- **PIL/Pillow** - работа с изображениями
- **Предобработка** - улучшение качества для лучшего распознавания

### Аналитика

- **Pandas** - анализ и обработка данных
- **NumPy** - математические вычисления
- **Автоматические отчеты** - ежедневные и месячные сводки
- **Рекомендации** - AI-анализ паттернов расходов

## Функциональность

1. **Загрузка и обработка чеков**
   - Фотографирование чека через Telegram
   - Автоматическое OCR распознавание

2. **Категоризация расходов**
